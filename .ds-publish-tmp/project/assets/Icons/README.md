# Icons

Line icons from the [Lucide](https://lucide.dev) set (24px, 2px stroke, round caps), drawn with `stroke="currentColor"` — they recolor with CSS `color`, unlike the wordmark. The codebase has ten; three representative ones are included here as a sample rather than the full set.

- `waves-horizontal.svg` — surf conditions, ocean.
- `calendar-event.svg` — events.
- `users.svg` — community, team.
