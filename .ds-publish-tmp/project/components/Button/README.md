# Button

Pill-shaped, three variants. **Primary** (filled brand blue, navy label) at most once per view, for the one action the screen is for. **Secondary** (outlined, navy label) and **ghost** (outlined, muted label) for everything else. Verb first, sentence case: "Get the app", not "Sign Up!". A `sm` size drops padding and font size for compact contexts — inline in a form, inside a card. Disabled drops to 60% opacity and blocks the pointer.
